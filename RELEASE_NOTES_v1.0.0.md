## 🚀 MODMASE v1.0.0 — Initial Release

The first official release of the **MODMASE** Android app — your modding destination, now in your pocket. 💚

### ✨ What's new

**🏠 Home**
- Animated MODMASE banner with a glowing, floating border
- One-tap **Join Telegram** and **Open Website** buttons
- Category cards: Android MODs, Apps & Tools, Games, Updates
- Modding Resources & Guides shortcut

**🧰 Tools**
- Live **RAM** and **storage** monitor with animated bars
- Device info (model, Android version, board, CPU ABI, display, security patch) with copy button
- Rotating mod safety tips
- Quick shortcuts: Developer options, All apps, Storage, About phone
- Copy Telegram / Website links and share MODMASE with friends

**ℹ️ About**
- Channel welcome info and what you'll find on MODMASE
- MODMASE Team card and quick links

**🎨 Design**
- Aesthetic dark UI with neon-green theme taken from the MODMASE banner
- Animated splash screen, aurora background, floating particles
- Smooth staggered animations and floating bottom navigation
- Poppins and Pacifico fonts

### 📲 Installation
1. Download **`MODMASE-v1.0.0.apk`** from the assets below.
2. Allow *Install from unknown sources* if Android asks.
3. Install and open **MODMASE**.

### 📋 Requirements
- Android 7.0 (API 24) or higher

### 🔐 Privacy
- No internet permission requested
- No ads, no tracking, no data collection
