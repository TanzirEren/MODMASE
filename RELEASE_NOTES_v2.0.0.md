## 🚀 MODMASE v2.0.0

The biggest update yet: MODMASE is now live, connected and packed with tools. 💚

### ✨ New
- **📰 Live updates feed**: new mods and news appear instantly, with images and an "Open in Telegram" button.
- **🔔 Push notifications**: get notified about new releases. Choose categories in Settings.
- **🔄 Update checker**: the app tells you when a new version is available.
- **📱 Apps library**: browse MODs, Apps, Games and Tools with search, filters, screenshots, features, SHA-256 and download.
- **🧰 Toolbox**: Hash Checker, Device Export, Battery & Network, QR Generator and Mod Request.
- **🛠️ 12 modder tools**: APK Inspector, Permission Scanner, Signature Compare, Version Comparator, Base64, Text Hash, Hex/Bin/Dec, Color Converter, dp/px, JSON Formatter, API Level Guide, ADB cheats.

### 🎨 Design
- Lottie splash and swipeable onboarding
- Shimmer loading and smooth card animations
- Haptic feedback and animated toast messages
- Optional Material You colors (Android 12+)
- App icon shortcuts and a home screen widget

### 📲 Installation
1. Download **`MODMASE-v2.0.0.apk`** below.
2. Allow *Install from unknown sources* if asked.
3. Open MODMASE and follow the quick intro.

### 📋 Requirements
Android 7.0 (API 24) or higher. Internet is needed for the feed, library and notifications. All tools work offline.

### 🔐 Privacy
No ads and no tracking. Push uses Firebase topics only, and files you select in tools never leave your device.
